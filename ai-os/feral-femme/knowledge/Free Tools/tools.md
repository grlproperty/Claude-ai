# Free tools

All free: no account, no sign-up, no payment. The label scanner states that nothing typed or photographed leaves the page.

| Tool | What it does |
|---|---|
| Label scanner ("Check a label") | Reads a product label back: animal-derived ingredients, selling words, what each certification does not cover |
| Spot the Greenwash | Ten claims to judge, with a shareable score card |
| Message Builder | Writes a message asking a brand what evidence supports a claim |
| Claim Checker (for brands) | Checks pasted copy against 36 terms |
| Certification Decoder | 22 schemes — who runs them, what they verify, what they do not |
| Greenwashing Decoder | 36 terms — what is implied, what is meant |
| Material Decoder | 21 materials — welfare position, environmental cost, alternatives |
| Ingredient Decoder | 53 substances |
| Record Checker | 21 documented findings, each with a named source |
| Where to Act | 10 organisations, filterable by subject |

**To confirm:** the live home page lists ten tools but also says "Eleven free tools"; `content/site.json` says nine; the repository README says six. The counts should be reconciled.
